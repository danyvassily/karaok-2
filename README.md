# Karaok Party

Documentation de conception d’une application de karaoké macOS gratuite et open source : moteur audio temps réel Rust, microphone **Nothing Headphone (a) en USB-C**, fichiers musicaux locaux, séparation voix/accompagnement, paroles pilotées par la musique et effets live.

Le projet est au stade de conception : aucun moteur, casque ou benchmark n’est présenté comme testé.

- [Spécifications techniques](SPECIFICATIONS_TECHNIQUES.md)
- [Prompt master pour agents](MASTER_PROMPT.md)
- [Instructions courtes de projet](AGENTS.md)

La documentation exclut du périmètre actuel le micro iPhone, l’app iOS, QR, WebRTC et l’extraction de contenu Spotify/YouTube.
